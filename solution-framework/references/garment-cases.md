## 二、女装行业方案可参考的SOW对接模块

来源：sow-write (L419)

服装/鞋服推荐对接模块：

| 对接模块 | 说明 | 典型场景 |
|---------|------|---------|
| **会员** | 会员信息同步、等级规则、升降级 | URBAN会员体系搭建 |
| **积分** | 积分获取/消耗规则、积分抵现 | 江南布衣积分抵现案例 |
| **券** | 优惠券模板、发放、核销 | 江南布衣高管券叠加案例 |
| **订单** | 订单全链路同步 | 线上线下订单归因 |
| **商品** | 商品编码、分类、规格 | ERP→微盟同步，女装含颜色/尺码 |
| **门店** | 门店信息、库存、业绩 | 50家直营门店统一管理 |

商品对接字段（ERP→微盟）：

| 字段 | 微盟侧 | 说明 |
|------|--------|------|
| 商品编码 | outerGoodsCode | 以ERP侧为准 |
| SKU编码 | outerSkuCode | 规格组合唯一标识 |
| 商品分类 | categoryPath | 如"女装/连衣裙" |

## 三、售前总表现存服装项目关键信息

- **客户分类**：国内国际二线 / DTC品牌

- **系统底座**：智慧零售连锁版、会员运营增强版
