# GODIVA 歌帝梵 · 智慧零售案例

> **来源：** GODIVA Smart Retail 方案汇报（2026-05-16 阿信提供）
> **品牌类型：** 高端巧克力/冰淇淋/饮品 · 连锁门店
> **适用场景：** 食品零售混合业态（现制+成品）、即时零售、到店+到家双模式

---

## 一、品牌概况

| 维度 | 信息 |
|------|------|
| **品牌** | GODIVA 歌帝梵（比利时高端巧克力品牌） |
| **业态** | 现制冰淇淋/饮品 + 成品巧克力/蛋糕/饼干 混合零售 |
| **门店配置** | 每店2-3名店员，同时在店服务2人 |
| **日均单量** | 工作日~10单，非工作日40-50单 |
| **客群来源** | 线下：周边办公园区；线上：美团、饿了么、官网投放券 |
| **核心痛点** | 店员需同时制作产品+接待客户，等待时间长导致流失 |

## 二、双模式运营架构

### 模式一：到店/在店（门店模式）

```
消费者进线下店
    → 扫码点单（查看商品产地/配料/折扣）
    → 进线上店
    → 选品下单
    → 在线支付
    → 店员打包
    → 扫码核销
    → 自提离场
    → 邀请加企微并开卡
```

**业务价值：** 顾客进店扫码快速了解商品信息并自主下单，免去排队等待，避免意向客户流失。

### 模式二：离店/到家（外送模式）

```
企微推广 → 消费者微信内搜索GODIVA
    → 进线上店
    → 选品下单
    → 选择配送方式（快递/外送/自提）
    → 在线支付
    → 店员打包
    → 展示配送轨迹
    → 三方运力取餐 → 送货上门
```

**业务价值：** 线上云店扩展门店经营时间和空间，消费者随时随地点单，配送状态实时可见，半小时配送到家，财务数据规范清晰。

## 三、巡店调研模板（可复用）

| 分类 | 调研问题 |
|------|---------|
| **门店基本情况** | 店员数量、同时在店人数 |
| **店员日常工作** | 接待流程、POS操作、产品制作、外卖接单发货 |
| **客户渠道** | 线下来源、线上平台（美团/饿了么/官网） |
| **成交量** | 工作日/非工作日日均单量 |
| **产品推荐** | 搭配推荐方式 |
| **下单核销** | POS点单、POS扫码核销 |
| **新客开卡** | 入会引导方式、企微加好友流程 |
| **离店触达** | 离店后如何触达、是否有离店交易场景 |
| **营销推送** | 生日/纪念日是否有营销推送 |
| **商品结构** | 产品类型（半成品/成品）、促销折扣方式 |
| **临期品处理** | 临期产品处理渠道 |

## 四、云店建设四通（食品零售版）

| 打通项 | 说明 |
|-------|------|
| **会员通** | 身份识别、信息同步、统一会员、全域会员打通；积分增删改查、优惠券领取核销、全域权益统一 |
| **商品通** | 同款同价同折扣、线上线下一盘货；门店库存（线下实时库存）、总店库存、外部仓库存 |
| **订单通** | 外部订单导入、线上下单线下提货、导购全域可视化 |
| **营销通** | 线下促销（满赠/会员折扣/限时折扣）；线上促销工具同步（无门槛抵扣券/兑换券/随机满减券） |

## 七、适用场景

- 食品零售品牌（巧克力/冰淇淋/烘焙/饮品等现制+成品混合业态）
- 有线下门店+线上外送双渠道需求的品牌
- 需要对接美团/饿了么等三方平台的即时零售场景
- 门店人员需同时承担制作+销售双重角色的业态
